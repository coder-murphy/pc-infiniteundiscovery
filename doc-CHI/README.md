# Infinite Undiscovery / ASKA 引擎中文整理（doc-CHI）

本目录是 [`docs/`](../docs/) 英文逆向笔记的中文梳理，按"引擎功能 / 数据格式 / 工具链 / 跨作品谱系"重新组织。英文原文仍是第一手记录；这里做的是归纳、串联与给出阅读入口，不新增未经测量的结论。

> 前提：所有结论都是从零售光盘数据"从外部"观察得到的，可被推翻。RTTI 给出的是**类型名字**，不是函数体、字段布局或调用图；凡涉及"这个类做什么"的地方都是解读，不是反编译结果。历史上已有多条结论被后续会话修正，详见 [12-现状与未解问题](12-现状与未解问题.md)。

## 一句话结论

《Infinite Undiscovery》（tri-Ace / Square Enix，Xbox 360，2008）是 tri-Ace 自研 **ASKA** 引擎的第一款作品。零售可执行文件保留了完整 C++ RTTI，单是类型名就还原出 **1 740 个类**：引擎命名空间 `Aska::` 很薄（63 个类型），游戏逻辑全部放在全局命名空间并用匈牙利前缀。引擎的能力面覆盖任务调度、异步资源流、渲染与后处理、AHSL 着色工具链、行为树 + 状态机 AI、A* 导航、编译型战斗回调、场景脚本、音频与自研容器库。数据侧，两张光盘的容器、压缩、纹理、场景、动画、碰撞、脚本、导航网格、音频与着色器**均已读到可验证的程度**。

## 引擎功能地图

| 能力域 | 已知的引擎侧内容 | 对应数据/格式 |
| --- | --- | --- |
| 应用与调度 | `Aska::App`、`Task`、`FiberTask`、`Thread`、`ObjectManagerWorkerThread` | — |
| 内存 | `Aska::MemoryManager`、自研容器库 | — |
| 资源流式加载 | `ResourceManager` 及 Load / IntermediateLoad / Decompress 三段通知 | NORM、SLZ |
| 文件处理 | `AofHandler`、`AsfHandler`、`AcfPrimitiveData_*` | AOF / ASF / ACF |
| 渲染 | `RenderPassManager`、`RenderableObject`、`PrimitiveBufferXe`、`ShadowManager`、`FrustumObject` | ASF、AIF、AHSL |
| 后处理 | `BackBufferEffect`、`CameraFilter`、亮度对比、单色、帧残留、交叉淡化 | 固定着色器库 |
| 相机 | `Camera`、`CameraSynchronizer`、`AFPoint` | SNC/AAF 中的相机节点 |
| 动画与层级 | `Joint`、`HierarchicalObject(Container)`、`IAnimatable`、`AimingObject` | AAF、ASF `tree` |
| 物理与风 | `Dynamics`、`DynamicsForceEmitter`、三种风场 | ASF 中未读的尾部块 |
| 碰撞 | `CollisionHandler`、`ILandscapeConstraint` | ACF、NODE |
| AI | 行为树 + FSM + A* + 感知 | NODE、FSM 类名 |
| 战斗 | 342 个 `Btl…` 类型、47 个弹道回调、26 个信号回调 | — |
| 场景脚本 | `CSceSceneController`、`CSceDelayTask`、`sce::Var` | SNC |
| 音频 | AAC/XMA2、波表合成器 | AAC |
| 着色工具链 | AHSL、`AHSX` 磁盘缓存、MS XDK 编译器 | 60 + 20 517 个程序 |
| 视频 | YUV 转换着色器、WMV 流 | 容器间隙中的 ASF/WMV |
