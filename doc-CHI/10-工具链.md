# 10 工具链

全部是独立 Python 3 工具，无强依赖（`xex.py` 有 pycryptodome 时用，否则回落到内置纯 Python AES；`aif.py` 自带无依赖 PNG 写出）。每个工具都对**用户自己提供的文件**操作，仓库不附带任何零售数据。

## 工具一览

| 工具 | 做什么 | 关键子命令 |
| --- | --- | --- |
| `xdvdfs.py` | 读光盘 XDVDFS：卷信息、完整文件列表、提取 | `info` / `list` / `extract` |
| `mron.py` | 在镜像内**原地**走 NORM/MRON 容器；列表、CSV、按类型普查、按标签提取并解压 | `scan` / `census` / `extract` |
| `slz.py` | SLZ 包装：x360 的 XCompress + PlayStation 的三种 LZ77；解压、批量自校验、PS 镜像普查 | `info` / `decompress` / `verify` / `scan` |
| `lzx.py` | XCompress 变体的 LZX 解压器（有状态、按帧），供其他工具调用 | （库） |
| `xex.py` | 读/解密 XEX2；结构化头输出；恢复 PE | `info` / `extract` |
| `rtti.py` | 从 PE 的 MSVC RTTI 恢复类清单并 demangle | `list` / `groups` |
| `xdbf.py` | 读 XDBF：成就（多语言）、字符串表、内嵌 PNG | `info` / `achievements` / `strings` / `images` |
| `disasm.py` | 找字符串背后的代码：MIPS（PS1/PS2）或 PowerPC（Xbox 360，需 `--base`）；指针表 + 反汇编 | `strings` / `xref` / `table` / `dis` |
| `aska.py` | 一次扫描 25 种引擎签名（两种字节序），判断文件是否属于 ASKA | `identify` / `compare` |
| `aif.py` | 读 AIF 纹理：头、Xbox 360 去平铺、DXT/未压缩解码、写 PNG | `info` / `png` |
| `asf.py` | 读 ASF 场景：块树、节点图、完整顶点格式、材质与纹理、OBJ+MTL+PNG 导出、批量自校验 | `tree` / `info` / `obj` / `materials` / `skeleton` / `textures` / `check` |
| `aaf.py` | 读 AAF 动画：树、某一时刻姿态、静止姿态与场景对照、批量校验 | `tree` / `info` / `pose` / `rest` / `check` |
| `acf.py` | 读 ACF 碰撞：球树、图元、OBJ 导出、批量校验 | `tree` / `info` / `obj` / `check` |
| `snc.py` | 读 SNC 脚本：摘要、反汇编、字符串表、数据块、批量校验 | `info` / `dis` / `strings` / `blocks` / `check` |
| `node.py` | 读 NODE 导航网格：节点、链接/代价、分区、可行走地面 OBJ、批量校验 | `info` / `nodes` / `links` / `partitions` / `obj` / `check` |
| `shader.py` | 全部着色器：扫描、解析、反汇编 Xenos 微码、常量表校验、两作对比、打印 opcode 表 | `scan` / `verify` / `list` / `dis` / `compare` / `optable` |
| `aac.py` | 读 AAC 音频容器：目录、导出 RIFF-XMA2 或 PCM、在字节区里查找容器、批量校验 | `info` / `xma` / `wav` / `bank` / `find` / `verify` |
| `vmtoc.py` | Eternal Sonata 的 `index.vmtoc` 与两层压缩（Okumura LZSS + Subbotin 区间编码） | `list` / `verify` / `extract` |
| `pkg.py` | 读 PlayStation `.pkg`（PS3 已解，Vita 半解） | `info` / `list` / `extract` / `decrypt` |

## 常用命令

### 光盘与容器

```
python tools/xdvdfs.py info    "path/to/disc1.iso"
python tools/xdvdfs.py list    "path/to/disc1.iso" --csv disc1.csv
python tools/xdvdfs.py extract "path/to/disc1.iso" extract/disc1

python tools/mron.py census  "path/to/disc1.iso" --offset 1703536640 --length 2207584256
python tools/mron.py extract "path/to/disc1.iso" --offset 1703536640 --length 2207584256 --tag MTEX --decompress extract/textures
```

### 纹理与模型

```
python tools/aif.py info  extract/textures/317BD800_003_MTEX.aif
python tools/aif.py png   extract/textures/317BD800_003_MTEX.aif texture.png

python tools/asf.py info      extract/models/000A4000_006_MESH.asf
python tools/asf.py materials extract/models/000A4000_006_MESH.asf
python tools/asf.py obj       extract/models/000A4000_006_MESH.asf sword.obj --textures
python tools/asf.py skeleton  extract/models/53EC3800_000_MESH.asf
python tools/asf.py check     "extract/models/*.asf"
```

### 动画、碰撞、脚本、导航

```
python tools/aaf.py tree  extract/anim/000A4000_008_ANIM.aaf
python tools/aaf.py pose  extract/anim/000A4000_008_ANIM.aaf --time 40
python tools/aaf.py rest  "extract/anim/*.aaf" --models "extract/models/*.asf"

python tools/acf.py tree  extract/coll/49450000_036_COLL.acf
python tools/acf.py obj   extract/coll/49450000_036_COLL.acf collision.obj
python tools/acf.py check "extract/coll/*.acf" --models "extract/models/*.asf"

python tools/snc.py info    extract/scene/4F0A3000_041_SCE.bin
python tools/snc.py strings extract/scene/4F0A3000_041_SCE.bin
python tools/snc.py dis     extract/scene/4F0A3000_041_SCE.bin --limit 40 --blocks
python tools/snc.py check   "extract/scene/*.bin"

python tools/node.py info  extract/scene/17C48000_005_NODE.bin
python tools/node.py links extract/scene/17C48000_005_NODE.bin --limit 5
python tools/node.py obj   extract/scene/17C48000_005_NODE.bin navmesh.obj --portals
python tools/node.py check "extract/scene/*NODE*.bin"
```

### 音频

```
python tools/aac.py bank "path/to/disc1.iso" --offset 0x8E75C000 --length 143654912
python tools/aac.py info "path/to/disc1.iso" --offset 0x8E75C000 --length 3842048
python tools/aac.py xma  "path/to/disc1.iso" music/ --offset 0x8E75C000 --length 3842048
python tools/aac.py verify "extract/sound/*.bin"
```

### 着色器与可执行文件

```
python tools/shader.py scan    "path/to/disc1.iso"
python tools/shader.py verify  "path/to/disc1.iso"
python tools/shader.py list    "path/to/disc1.iso"
python tools/shader.py dis     "path/to/disc1.iso" --lib 25
python tools/shader.py compare "disc1.iso" "so4.iso"

python tools/xex.py  info    extract/disc1/default.xex
python tools/xex.py  extract extract/disc1/default.xex extract/disc1/default.exe
python tools/rtti.py groups  extract/disc1/default.exe
python tools/rtti.py list    extract/disc1/default.exe --filter "Aska::"
python tools/xdbf.py achievements extract/disc1/default.exe
```

### 跨作品判断

```
python tools/aska.py identify "path/to/any/image_or_container"
python tools/aska.py compare  report1.json report2.json
```

## 设计取向

* **原地读取**：`mron.py` 直接在镜像里按偏移走容器，12 GB 的容器不需要先解出来。
* **自校验**：几乎每个工具都有 `check`/`verify`，用文件自报的长度、冗余字段或跨格式关系验证解码，而不是"看着像"。
* **失败要显式**：例如"0x18 处没有 XCompress magic"通常是 SLZ 存储块，不是 bug；`aska.py` 会把命中数与偶然概率比较，避免几 GB 镜像上的一次巧合被印成"可能是 ASKA"。
